# uSwift

## The Micro Swift standard library

This was built by basically starting as tiny as possible (see https://github.com/carlos4242/uSwift) and slowly adding pieces as required. This makes a very different standard library from what you might be used to but it has worked well
for us, adding pieces over time and under our control. For example there's no Dictionary and no String! But it works
well for the very limited and specialised type of programming that fits on very small microcontrollers (8-bit).

The runtime is even more tiny. The bloat that can be accused in Swift is absent.

Feel free to copy and experiment but I'm afraid don't expect support, this is actively maintained exclusively for
the S4A IDE and nothing else at this time.
